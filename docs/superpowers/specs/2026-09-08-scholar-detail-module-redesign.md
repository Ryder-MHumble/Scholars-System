# 学者详情模块重构设计

## 目标

将学者详情页中混杂的关系、兼职和学术成果信息拆成职责清晰的模块，并让所有资源通过对应的规范化数据表读写。减少页面上的重复操作入口，统一为模块级编辑弹窗。

## 范围

本次包含：

- 共建关系分类
- 学术兼职
- 学者成就：代表论文、专利、获奖、科研项目、开源项目
- 学者关系：合作学者、学者 News
- 学者详情相关页面的纯白画布和模块视觉统一

本次不包含“学院活动”。现有学院活动数据及接口不迁移、不删除、不接入新的学者关系界面。

## 信息架构

### 整页布局

统一处理学者详情页中的全部模块，包括左侧基础资料、中部业务内容和右侧学者关系。所有一级模块采用同一种无圆角外框分区语言，避免只有三个新增模块改变样式而其他区域仍保留悬浮卡片外观。

左侧基础资料中的头像身份、联系方式、个人简介、教育经历、研究方向等子模块保持原有信息顺序，但缩小子模块之间的纵向间距、上下内边距和标题与正文间距，提高首屏信息密度。联系方式和长文本仍保留足够点击区域与可读行高。

### 中部主内容

中部使用三个平级业务分区，不使用圆角矩形卡片外框：

1. 共建关系分类
2. 学术兼职
3. 学者成就

分区使用标题、留白、细分隔线和必要的浅色内容底来建立层级。每个分区标题栏只保留一个铅笔编辑图标。

### 右侧学者关系

右侧保留“学者关系”模块，移除人数或条数徽标。标题栏只保留一个铅笔编辑图标。展示页签为：

- 合作学者
- 学者 News

不展示学院活动页签。

## 编辑交互

每个模块点击标题栏编辑图标后打开独立弹窗。弹窗提供明确的逐条新增和批量识别入口，已有记录可逐条删除。

- 共建关系分类：逐条选择或新增分类、批量识别、删除。
- 学术兼职：逐条新增、批量识别、删除；数据来自 `scholar_academic_positions`。
- 学者成就：在一个弹窗中用页签管理五类成果。
- 学者关系：在一个弹窗中管理合作学者和学者 News；News 支持批量识别导入。

删除操作需要明确的二次确认或可识别的危险状态，成功后立即刷新当前模块；失败时保留弹窗内容并显示错误。

## 学者成就

学者成就展示页签：

- 代表论文
- 专利
- 获奖
- 科研项目
- 开源项目

代表论文、专利、获奖和科研项目支持新增、编辑、删除及批量识别。

开源项目展示项目名称、stars 和项目链接，按 stars 数量降序排列。开源项目不提供字段编辑或手工逐条新增，只允许删除；新增通过批量识别完成。数据来自 `scholar_open_source_projects`。

科研项目数据来自 `scholar_research_projects`，不再使用旧的 `joint_research_projects` 作为详情页资源写入目标。

## 数据契约

- 学术兼职：`scholar_academic_positions`
- 学者 News：`scholar_news`
- 科研项目：`scholar_research_projects`
- 开源项目：`scholar_open_source_projects`
- 代表论文、专利、获奖：沿用现有对应成就接口
- 合作学者：沿用现有合作学者数据契约，并补充删除能力
- 共建关系分类：沿用 `project_tags` / `is_cobuild_scholar` 关系接口

前端详情类型需要显式声明四类规范化资源。新增、批量写入、删除后应重新获取或局部更新对应资源，避免继续写入 `recent_updates`、`joint_management_roles` 或通用 JSON 字段。

## 视觉规范

- 应用主画布和学者详情页面背景统一为纯白色。
- 学者详情页全部一级模块，包括左侧基础资料、中部内容和右侧关系模块，均不使用圆角矩形外框或悬浮卡片阴影。
- 整页模块使用一致的标题、留白和细分隔线区分，标题字号保持紧凑。
- 左侧基础资料子模块压缩纵向间距和上下内边距，但正文行高、按钮点击区域和信息可读性不得降低。
- 重复数据项可以保留小半径边框，弹窗保留清晰边界；不嵌套装饰性卡片。
- 图标按钮提供可访问名称和悬停提示，焦点状态清晰。
- 桌面端保持三栏信息密度；窄屏下按主资料、核心模块、学者关系顺序纵向排列，避免固定宽度溢出。

## 验收标准

- 页面可见三个平级业务模块，且每个标题栏只有一个编辑图标。
- 页面主背景为纯白，左、中、右全部一级模块均没有圆角矩形外框和悬浮阴影。
- 学者基础信息各子模块间距明显缩小，同时不发生文字、图标或操作控件拥挤重叠。
- 四类规范化资源均从对应接口读取并写回对应表。
- 开源项目显示名称和 stars，排序正确，仅提供删除。
- 学者关系不显示数量，合作学者和 News 均可删除，News 可批量导入。
- 学院活动不在本次界面和数据变更范围内。
- 新增、删除、批量识别的成功和失败状态均有用户反馈。
- 桌面和移动视口无文字或控件重叠，键盘可操作编辑入口和弹窗。

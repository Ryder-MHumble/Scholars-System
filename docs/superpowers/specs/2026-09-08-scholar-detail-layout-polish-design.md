# Scholar Detail Layout Polish Design

## Goal

修复学者详情页桌面三栏中的边缘图标与 Tooltip 裁切问题，并收紧中栏的信息层级，使共建关系分类和学术成果的展示符合当前产品要求。

## Scope

- 保留桌面端左、中、右三列独立滚动以及隐藏滚动条的交互。
- 修复左、右列靠近滚动边界的操作图标和 Tooltip 被裁切的问题。
- 调整中栏模块顺序和标题层级。
- 精简共建关系分类的只读展示。
- 不修改后端 API、数据库结构、资源编辑弹窗或移动端单列行为。
- 不使用浏览器、Playwright 或其他可视化辅助进行验证。

## Layout

桌面端继续使用固定宽度左右栏和自适应中栏。滚动职责仍由三列容器承担，但每列增加足够的边缘安全间距，组件内部不再使用会截断浮层的无必要 `overflow-hidden`。页面保持纯白背景、无平级圆角卡片，通过细分隔线、标题字号和紧凑留白表达层级。

左侧个人主页链接 Tooltip 使用挂载到 `document.body` 的浮层，并根据触发按钮的位置使用 `fixed` 坐标定位。这样 Tooltip 不受任一滚动祖先的裁切；鼠标离开、失焦或滚动导致按钮卸载时正常关闭。没有 DOM 的测试环境保持可渲染。

右侧模块的编辑入口通过列内安全间距与滚动边界分离，避免图标及其原生提示贴边或被截断。

## Middle Column

中栏按以下顺序展示：

1. 共建关系分类。
2. 可折叠的学术兼职。
3. 学术成果标题和唯一编辑图标。
4. 学术标识。
5. 代表论文、专利、获奖、科研项目和开源项目标签页。

删除当前中栏顶部的“学者成就”标题和编辑入口。新的“学术成果”标题位于学术标识与成果标签页共同区域上方，右上角保留唯一的编辑图标，并继续打开现有 `EditAchievementsModal`。

## Project Category

共建关系分类的只读状态仅展示：

- “共建关系分类”标题。
- 一个编辑图标。
- 已选择的项目分类标签。

删除“共建导师/未建立关系”状态、解释文案和空状态说明。没有分类时标题行仍保留，标签区域为空。点击编辑图标后继续复用现有分类选择器和保存逻辑，不改变数据格式。

- 左侧栏测试验证 Tooltip 通过浮层渲染，不位于裁切容器内。
- 运行聚焦 Vitest 测试和生产构建。
